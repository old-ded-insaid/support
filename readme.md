ПАРСЕР ЛОГОВ ЧЕКОВ — как пользоваться
=======================================

ЗАПУСК
    Дважды кликни ParserLog.exe. Больше ничего делать не нужно:
    Java уже встроена в папку runtime, установка не требуется.


КУДА КЛАСТЬ ЛОГИ
    Главный способ: скопируй нужные .txt файлы ПРЯМО В ЭТУ ПАПКУ,
    рядом с ParserLog.exe. Программа сама их найдёт и прочитает.

    Также можно перетащить .txt файл из проводника прямо на окно
    программы или нажать "Выбрать файл...".

    Если рядом с exe есть папка src — она тоже читается целиком,
    вместе со всеми вложенными .txt.

    ВАЖНО: если файл не выбран, читаются ВСЕ .txt рядом с программой.


ПОИСК
    Время   — можно пустым. Например 21:15 или 21:15:30 или
             полная дата вида 03.10.2026 21:15:30.000
    Сумма   — сумма чека, например 1234.56
    Слово   — любое слово или фраза, регистр не важен
    Окно    — сколько минут до и после указанного времени искать
             (по умолчанию 10, то есть всего 20 минут)

    Enter в любом поле — сразу начать поиск.


ПРОЧИЕ ВОЗМОЖНОСТИ
    Ctrl + колесо мыши — увеличить/уменьшить шрифт
    Ctrl + плюс/минус   — то же с клавиатуры
    Колесо               — прокрутка на 9 строк
    Кнопка темы          — переключить светлую/тёмную, выбор запоминается

    Настройки (тема и шрифт) хранятся в файле
    %USERPROFILE%\parser_log_settings.properties


ЕСЛИ НЕ ЗАПУСКАЕТСЯ
    В этой же папке есть ParserLog_diag.exe — запусти его, он покажет
    код ошибки и откроет лог в блокноте.
